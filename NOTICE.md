# Attribution and scope

OSPARK Starter is a **new, independently implemented public reference project** inspired by the creator's private OSPARK work.

The public starter does **not** include private OSPARK runtime code, JARVIS source files, Hermes code, model weights, imported 3D assets, fonts, proprietary sound effects, copied upstream documentation, or screenshots of any private services.

## Related projects

- **OSPARK**: The private agentic operating environment whose architecture and design principles motivated this starter. This repository is not its production source.
- **Hermes Agent** (Nous Research): An optional, separately installed external gateway. No Hermes code is bundled.
- **JARVIS / adewaskar**: A historical interface inspiration for the private OSPARK project. No JARVIS code is bundled here. If future contributors import upstream JARVIS source, they must preserve the applicable MIT copyright and license notices, and identify the changes.

This project uses standard browser APIs and Node built-in modules. OSPARK and other named marks remain the property of their respective owners. This reference project does not claim endorsement by upstream maintainers.
