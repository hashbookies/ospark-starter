# OSPARK Starter v0.1.0

First standalone, public-oriented reference edition.

## What's ready

- Animated local-first Canvas2D orbital interface and startup sequence.
- Desktop and mobile layouts, reduced-motion handling and keyboard text input.
- Simulated demo mode with four health scenarios and no backend prerequisites.
- Read-only operational health for compatible loopback gateway, inference and Mission Control APIs.
- Per-source degraded-state details, 30-second polling and stale detection.
- Explicitly simulated sample delegation review, with no real acceptance or dispatch.
- Optional disabled-by-default tool-free local model chat adapter.
- Original source, example configuration, tests, MIT license and publication guidance.

## Verification at packaging time

- Node 22.16, sixteen automated tests passing.
- JavaScript syntax validation passing.
- HTTP server tested in demo and connected/unconfigured modes.
- Browser UI smoke-tested using local static HTML + mocked same-origin API responses (network navigation was restricted in the packaging environment).
- Candidate scanned for common token patterns, private macOS home paths and personal names. This is **not** a comprehensive third-party secret audit.

## Boundaries

Not the private OSPARK source tree, not the same React/Vite application, and not the live controller-worker runtime. No voice service, autonomous tool use, mission dispatch or genuine task approval is included. The frontend status and demo data are intentionally distinct from real, trusted operational evidence.
